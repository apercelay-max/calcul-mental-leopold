# Calcul mental Léopold

Application d'entraînement au calcul mental destinée à Léopold.

## Objectif

Proposer des exercices de calcul mental (addition, soustraction, multiplication, division...)
adaptés à son niveau, pour s'entraîner de façon ludique et régulière.

## Utilisation

Application web statique (HTML/CSS/JS, sans dépendance). Ouvrir `index.html` dans un navigateur,
ou jouer en ligne via GitHub Pages une fois activé sur ce dépôt.

- Choix de l'opération : addition, soustraction, multiplication, division, ou mélange
- 3 niveaux de difficulté
- 10 questions par partie, score et temps chronométré
- Meilleur score sauvegardé localement par mode/niveau
