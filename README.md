# Calcul mental Léopold

Application d'entraînement au calcul mental destinée à Léopold.

## Objectif

Proposer des exercices de calcul mental (addition, soustraction, multiplication, division...)
adaptés à son niveau, pour s'entraîner de façon ludique et régulière.

## Statut

Projet en cours de démarrage — le dépôt vient d'être créé, l'application reste à construire.
